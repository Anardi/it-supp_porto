
# Network Infrastructure & Troubleshooting Lab
A collection of networking labs using Cisco Packet Tracer, focused on network configuration, troubleshooting, and basic network services.

## Projects
- DHCP Configuration & Troubleshooting
- DNS Configuration & Troubleshooting
- FTP & TFTP Services
- LAN Connectivity
- SSH Switch Management

## Tools
- Cisco Packet Tracer

## Objectives
- Practice network configuration and troubleshooting.
- Understand common network services.
- Document problems, solutions, and verification results.
