# Linux System Administration Lab
A practical Linux administration lab covering user management, file permissions, service troubleshooting, network configuration, remote access, and system log analysis.

## Tools
- Operating System: Ubuntu Server
- Virtualization: Oracle VirtualBox
- Access Method: Local terminal and SSH

## Objectives
- Manage Linux users, groups, and file permissions.
- Inspect system resources and network configuration.
- Configure and troubleshoot SSH access.
- Monitor system services and logs.
- Apply basic host firewall rules.
